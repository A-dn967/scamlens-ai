# 🛡️ ScamLens AI – AI-Powered Scam & Phishing Detector

**Don't Trust. Verify.**

ScamLens AI is an AI-powered cybersecurity application designed to help users identify suspicious messages, phishing attempts, financial fraud, fake scholarship offers, and social engineering attacks.

Users can submit suspicious messages and receive an AI-generated security assessment, including a risk score, suspicious indicators, explanations, and safety recommendations.

## 🚀 Features

- **AI Scam Detection:** Analyzes suspicious messages using Groq AI.
- **Risk Assessment:** Generates a risk score from 0–100.
- **Threat Classification:** Identifies potential phishing, financial scams, impersonation, and other threats.
- **Warning Indicators:** Highlights suspicious phrases and patterns.
- **Security Recommendations:** Provides practical safety advice.
- **Multiple Languages:** Supports English, Urdu, and Roman Urdu analysis.
